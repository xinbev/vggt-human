# v2 附录方法与评测说明（中文对照）

本文档对应 .paper/my_paper/versions/v2/appendix_en.tex 中的方法、训练、评测协议和推理算法段落，便于核对英文表述。实验结果数值仍以论文中的英文表格和已归档评测输出为准。

## B4：指标与评测协议

### SHOW 人体-场景一致性

Table 2 使用 SHOW 定义的人体-场景一致性指标。每帧将 SMPL 网格投影到相机图像，生成选择场景深度观测的人体区域 mask；可见人体表面通过网格投影和相机视角下的可见性判断获得。场景深度无效点先剔除，再分别按第 5 至第 95 百分位或第 10 至第 90 百分位过滤边界异常值，得到下标为 5 或 10 的指标。指标在相机坐标系下逐帧计算，再按有效帧聚合。

HS-CF 衡量可见人体表面与 mask 内场景点之间的最近邻距离，并按可见人体点的深度离散范围归一化。HS-V 比较人体表面点与 mask 内场景点在图像水平、垂直方向上的空间方差。前者反映表面位置差异，后者反映空间尺度和范围差异。所有方法使用相同的 SMPL 反投影 mask、百分位过滤、坐标约定、最近邻方向和帧聚合规则。

### UniCon3R 物理落地指标

Table 3 遵循 UniCon3R 报告的 HuMoS 物理落地协议。协议从重建场景估计稳健地面高度，并采用 5 mm 容差。对有效帧 f，令 z_f 为该帧人体网格最低顶点相对估计地面的有符号高度；F 是有效帧集合，F_pen={f∈F:z_f<−τ}，F_float={f∈F:z_f>τ}，τ=0.005 m。Coll. 是 F_pen 占所有有效帧的百分比；Pen. 是 F_pen 中 −z_f 的条件均值；Float 是 F_float 中 z_f 的条件均值；P.Max 是 F_pen 中 −z_f 的最大值。Pen.、Float 和 P.Max 均以厘米报告；无对应事件的集合贡献 0，遵循 HuMoS 实现。四项指标越低越好。UniCon3R 说明采用稳健地面估计并遵循 HuMoS，但正文未公开地面估计器和数据集级聚合的详细实现；附录据此给出逐帧定义，不声称采用未公开的估计方法。

## C：方法与训练

### Body-Anchored Metric Calibration

SMPL 可见表面点投影到相对深度图，仅保留有限、正深度且在图像范围内的样本；投影冲突时保留最近的人体表面。解析尺度初值由人体表面深度与相对深度的比值中位数得到。24 个身体锚点编码人体状态、锚点位置与投影、局部场景几何、法线、偏移、距离和深度残差。锚点之间进行自注意力，并与各自的 3×3 场景邻域交叉注意力。汇聚表征预测残差 log-scale 和深度 bias。按置信度合并逐人的预测，再对有效帧的 log-scale 做片段级聚合，并将结果应用于场景深度和相机平移。

标定损失由尺度、深度偏置和标定深度监督组成。有效深度像素集合记为 Ω，尺度项比较预测与真值尺度的对数，偏置项比较预测和目标深度偏置，深度项在 Ω 上计算标定深度与真值深度的平均绝对误差。尺度扰动训练路径中的 bias 目标为零。具体损失权重应从最终 checkpoint 对应配置读取；当前项目中没有能唯一对应论文报告模型的完整 run manifest，因此英文附录未杜撰权重。

### Dynamic Interaction Grounding

SMPL 表面划分为 96 个对应区域，每个区域由质心和 8 个采样顶点表示。每个区域采集四种空间支持：固定 3×3 窗口、固定 7×7 窗口、跟随投影区域范围的自适应邻域，以及局部支持以外的环形区域。它们分别提供局部、较宽固定范围、区域尺度和周边场景上下文。现有论文源未规定自适应邻域和环带的具体像素半径，最终实现配置需要记录这些数值。

实例级人体深度缓冲区记录当前人的 SMPL 可见深度。与其在深度一致性容差内匹配的场景样本归入当前人体通道；与场景观测一致但不属于当前人的样本归入环境通道。归属于其他人的样本不进入这两个注意力通道，只作为干扰特征汇总。深度一致性容差以 ε_own 表示，具体数值需要由最终实现配置提供。注意力仅在有效样本上执行；每个支持域和所有权通道得到一个池化 token 及有效支持率。空支持域的 token 和有效支持率均为零。

每个区域预测相机坐标系平移提案、区域 gate g_r=σ(a_r) 和 log-variance ℓ_r。通过有效支持指示量 m_r、gate 和逆方差权重 m_r g_r exp(-ℓ_r) 对区域提案加权平均。聚合提案逐坐标裁剪到界限 [-δ_max, δ_max]，再乘以人体级 gate g_p=σ(a_p)，得到根平移更新。两轮迭代共享参数；每轮更新后重算区域位置、观测归属和注意力上下文。相机参数、场景几何、人体姿态和形状保持不变。裁剪边界及人体 gate 的 readout 是最终模型配置的一部分，当前论文源没有给出数值。

### BEDLAM 训练与微调

场景估计器和人体估计器在训练期间冻结。首先使用 BEDLAM：场景 metric depth 和 SMPL 真值作为干净目标。通过合成乘性深度尺度扰动训练标定模块恢复真实 metric scale；残差头从解析尺度初始化出发，学习剩余尺度和深度偏置修正。

Grounding 阶段对真值人体根平移和场景尺度施加扰动，包含干净输入、单独尺度扰动、单独平移扰动及混合扰动，训练模型恢复原始 GT 平移，同时避免修改已经正确的输入。随后接入 EMDB 和 3DPW 微调 grounding 模块，并保持主干冻结，使用各数据集可用的人体与场景监督。项目当前没有一份同时记录 BEDLAM 到 EMDB/3DPW 全流程、数据划分、扰动分布及微调日程的唯一配置；这些信息需要与最终 checkpoint 一同核实，因此不在论文里编造优化器参数或噪声范围。

Grounding 总损失包含区域 vote、最终平移、gate、更新正则和状态损失。第 k 轮的 vote 目标是将当前根平移到目标平移的剩余位移，除以剩余更新轮数；有效区域的 vote 以支持有效性和可靠性加权，使用平均绝对误差监督。最终平移损失比较最后一轮根平移和目标根平移。Gate 标签仅在候选更新使平移误差至少改善预设 margin 时为正，并在有效样本上使用二元交叉熵。更新正则惩罚各轮应用的平移增量幅度。

状态损失分为三项：扰动样本恢复项，约束最后一轮结果接近目标根平移；干净样本 identity 项，约束输出不要偏离输入根平移；以及 no-worse 项，对更新后误差高于更新前误差的部分施加 hinge 惩罚。各项权重需从最终训练配置读取；当前源码不能确认唯一对应论文模型的完整权重组合。

## C4：推理算法

**输入：** RGB 视频、冻结的 VGGT-Ω 与 NLF，以及训练好的标定和 grounding 模块。  
**输出：** 共享世界坐标系中的 metric 场景点和人体网格。

1. 运行 VGGT-Ω，得到相对深度、相机参数和场景特征。
2. 运行 NLF，得到每个人的姿态、形状、根平移和置信度。
3. 将可见 SMPL 表面投影到相对深度，计算稳健解析尺度初值。
4. 编码身体锚点场景查询，预测有效帧的残差 log-scale 和深度 bias。
5. 在 log-scale 空间聚合有效帧，并校准场景深度和相机平移。
6. 以校准后的人体平移初始化根平移。
7. 执行两轮共享参数的 grounding：划分人体区域并采样四类支持；分离当前人、环境和其他人的证据；预测区域 vote、gate 和不确定度；聚合并裁剪根平移更新；更新后重算区域与上下文。
8. 将校准后的场景点和精炼后的人体网格变换到共享世界坐标系。

## D：附加结果说明

### Bonn 深度

Bonn 使用 balloon2、crowd2、crowd3、person_tracking2 和 synchronous 五个序列，每个窗口从第 30 帧开始。请求窗口超过序列长度时使用剩余帧，不补帧。metric depth 结果不拟合 GT 尺度或偏置；摘要按有效深度像素数加权。50 至 500 帧范围内，200 帧时 Abs Rel 最低（0.13640），δ<1.25 最高（0.88192）。

### TUM-Dynamic 相机轨迹

TUM-Dynamic 相机平移 ATE 在 8 个序列上先进行 Sim(3) 对齐再平均，50 帧时为 0.00299 m，500 帧时为 0.00692 m。Sim(3) 对齐会消除整体相似变换自由度，因此这是相对轨迹诊断，不代表绝对 metric scale。

### 速度测量边界

现有 benchmark 在 NVIDIA A800-SXM4-80GB 上输入 100 帧，张量大小为 [1,100,3,448,592]，512 balanced resize；5 次 warm-up，20 次 GPU 同步计时。VGGT+NLF 为 9.76 FPS，VGGT+NLF+HSI scale 为 5.29 FPS。计时不包含图像 I/O、resize、H2D、模型加载和 warm-up。该测试关闭 TRSTR、接触精炼和 Dynamic Interaction Grounding，因此这两个 FPS 不代表完整 GroundedHuman 的端到端速度，也不能直接作为正文完整模型速度比较。
