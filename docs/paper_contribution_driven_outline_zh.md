## 1. 全文唯一主线

### 1.1 一句话研究问题

当场景只有相对尺度、人体初始位置也存在误差时，如何在不改变人体局部姿态与形状的条件下，利用可靠几何证据校准共享场景尺度和各人物位置，得到一致的世界坐标重建？

### 1.2 一句话核心观点

人体是具有度量先验、但定位不完全可靠的参照物；因此，场景尺度与人体位置不能被无条件地视为两个独立校准问题。

“度量先验”比“天然精确标尺”准确。人体模板具有物理单位，并不意味着每个人的预测体型和绝对深度都准确。

### 1.3 三项贡献的逻辑分工

| 贡献 | 要回答的问题 | 方法角色 | 可选的机制补强，不作为当前重写前提 |
| --- | --- | --- | --- |
| C1：共享尺度与局部位移的结构化联合校准 | 同一几何残差究竟来自尺度错误还是人体位置错误？ | 组织共享变量、局部变量及其耦合关系 | 尺度单扰动、位移单扰动、混合扰动；与原级联路径比较 |
| C2：局部结构保持的受限校准 | 对齐时允许改变什么，不允许改变什么？ | 限定 C1 的更新空间，保护人体局部结构 | 局部结构不变检查；受限和扩展自由度的受控比较 |
| C3：证据可观测性驱动的选择性校准 | 当前证据允许更新哪些变量和方向？ | 决定 C1 的更新方向、幅度和拒绝条件 | 遮挡和退化实验；标量置信度与方向选择的比较 |

叙述顺序为 C1 → C2 → C3。数学定义时可先说明 C2 的固定变量，以免读者误以为 C1 会同时改变姿态与形状。

### 1.4 不再作为主贡献的内容

- 使用 VGGT-Ω 和 NLF：作为观测来源及已有能力，不包装为新骨干。
- 解析中位数粗尺度：作为初始化和消融对象，不单独承担最强创新。
- 24 个 anchor、96 个 region、网络层数：作为实现载体，不作为研究结论。
- 四个数据集上的评估：作为证据，不占用一条方法贡献。
- 人体与场景可视化效果：展示输出，不替代因果分析。
- 现有轨迹聚合：明确其实际作用，不从 clip 聚合扩大成新的时序学习模型。

## 2. 推荐题目与摘要

### 2.1 题目

主推荐：

**GroundedHuman: Structured Scale–Translation Calibration for Metric Human–Scene Reconstruction**

中文工作题目：

**GroundedHuman：面向度量人景重建的结构化尺度—位移校准**

理由：将最具区分度的“尺度—位移关系”放入题目；“Geometric Interaction Learning”过于宽泛，无法直接体现新主线。

若最终有充分视频一致性和时间维度证据，可在任务名称中保留 “4D”。不要仅凭视频输入暗示已设计时序状态模型或跨帧记忆。

### 2.2 摘要写成六个功能单元

1. **任务与要求：**单目视频人景重建需要人体、场景和相机共享物理尺度，而不仅是分别预测出这些对象。
2. **核心困难：**用人体校准场景时，人体初始位置误差会与场景尺度误差混淆，使固定人体参照或独立校准产生错误补偿。
3. **核心方法 C1：**分解视频级共享尺度与人物级局部位移，并利用几何一致性进行联合校准。
4. **约束原则 C2：**固定人体局部姿态与形状，仅在低维全局变量空间中更新，避免形变补偿。
5. **可靠性机制 C3：**根据区域方向证据选择更新，并通过重投影重新采集证据。
6. **结果与结论：**用最终版本的世界运动、度量深度和机制实验支持结论，只放最关键的两到三个结果。

摘要不逐个介绍 HSI、TRSTR、stabilizer 等内部名称；不罗列所有数据集；不把现有 v0.3 数值直接当作尚未实现的新版本结果。

## 4. Introduction：从矛盾出发，不从模型列表出发

### 第 1 段：定义成功标准

写什么：重建完整人景世界要求人体、场景和相机在共同度量坐标系中一致；局部人体看起来正确，并不意味着其世界轨迹或场景位置正确。

段末落点：问题不仅是能否重建，而是不同预测是否能够组成一致的世界。

删什么：过长的应用背景；泛泛的 “rapid progress”“fundamental challenge”；开头连续堆叠模型名称。

### 第 2 段：建立具体失败机制

写什么：人体具有度量先验，可用于约束场景；但人体位置本身是预测量。错误的人体深度可能使场景整体被错误缩放，随后的位置校准又可能补偿这一错误。

配合 Fig. 1 展示“同样接近的投影或局部残差，可能对应不同的世界几何”。

段末落点：关键瓶颈是尺度与位置误差的混淆，而不是简单缺少一个尺度回归头。

### 第 3 段：给出洞察，对应 C1

写什么：尺度是跨人物、跨帧共享的变量，人体位移是局部变量；二者具有不同的作用范围。利用这种结构组织观测，有机会减少错误补偿。

不要把“有机会区分”写成“任意条件下唯一恢复”。如果所有人物存在相同系统性深度偏差，增加人物数量不一定能解除歧义。

### 第 4 段：说明为什么需要 C2

写什么：如果允许姿态和形状随对齐目标任意变化，残差下降未必代表全局位置更正确。因此固定局部结构，将调整能力集中在需要校准的变量。

段末落点：方法追求的是全局几何修正，不是通过改写人体实现表面对齐。

### 第 5 段：说明为什么需要 C3

写什么：即使变量分工清楚，遮挡、缺失深度和退化几何仍会让部分更新没有充分依据。引入方向相关证据，决定何时更新、更新什么以及何时保持。

段末落点：可靠校准不仅要会修正错误，也要会避免无依据修正。

### 第 6 段：简述证据并列贡献

用一至两句说明评估覆盖世界运动、度量深度以及三项机制验证，再列出三项贡献。贡献列表要与方法小节和机制实验使用相同关键词。

避免连续两次完整复述方法流程。引言正文解释“为什么”，贡献列表概括“提出了什么、解决什么”。

## 6. Method：围绕研究问题重组现有模块

### 3.1 Problem Formulation and Scale–Translation Coupling

**本节问题：为什么尺度和人体位置必须放在同一个问题中讨论？**

首先定义输入、观测来源、待更新变量与输出。观测来源用一段写完；VGGT camera code 维度、cached layer 数量等移到附录。

建议最少保留这些记号：

- `D_t^r, K_t, R_cw,t, t_cw,t^r`：相对深度及 camera-from-world 相机参数。
- `V_tq^0`：固定局部姿态、形状解码后的未加根平移人体顶点，单位为米。
- `tau_tq^0`：初始相机坐标根平移，单位为米。
- `s > 0`：同一共同相对坐标系内一个 clip 的共享尺度。
- `delta_tau_tq`：各帧各人物的局部平移修正。

用一个紧凑残差说明耦合，作为研究动机而不是完整算法：

```text
u_tqi = pi(K_t, V_tqi^0 + tau_tq^0 + delta_tau_tq)
r_tqi = s D_t^r(u_tqi)
         - [V_tqi^0 + tau_tq^0 + delta_tau_tq]_z
```

在暂时固定投影位置的局部近似下，尺度变化和人体 Z 向位移都能改变该残差；真实更新还会改变投影位置与对应关系，因此需要重新取证。

接着说明共享尺度影响所有相关观测，而局部平移只影响对应人物。该作用范围差异是结构化校准的动机，不是无条件可辨识性证明。

必要边界：共享尺度假设要求输入深度和相机已处于共同相对坐标系；若各窗口有独立 gauge，应额外说明窗口对齐，不能直接把一个 scalar 用于任意整段视频。

### 3.2 Structured Calibration of Shared Scale and Local Translation

**本节问题：怎样利用共享—局部结构，而不让人体误差污染全局尺度？对应 C1。**

按四步写：

1. 可见人体表面提供鲁棒粗尺度，作为初始状态而不是绝对可信答案。
2. 人体条件特征与局部几何残差生成校准证据；现有 24-anchor HSI 放在这里解释。
3. 跨人物、跨时间聚合支持共享尺度，人物局部证据支持对应平移。
4. 明确尺度和位移实际怎样相互影响：联合预测、显式求解或交替更新，选定一种实现并给出可复现规则。

正文必须有一张变量依赖图或简短算法，显示哪些观测更新 `s`、哪些更新 `delta_tau_tq`、人物更新后是否重新计算尺度证据。

若使用总目标，必须标明每项如何计算、在哪里监督、推理时是否存在；不能给网络级联套上一个实际上未优化的联合能量函数。

已有基础：可见前表面粗尺度、人条件残差尺度、clip 聚合、向相机平移传播尺度。

待补强：初稿和现有记录描述的主要是先尺度后平移的级联，不能仅改称“联合”就获得误差归因机制。特别需要补充跨帧约束实际使用什么信息；若依赖人物关联，必须说明关联来源和身份错误处理。

**深度 bias 的处理决策：**原稿保留 `D^m = s D^r + b`，但主要训练记录使用零 bias 目标。建议主线先围绕乘法尺度与平移，保留 bias 时将其明确列为额外深度变量，并说明为何不会重新吸收尺度或人体位置错误。加性深度修正不等价于统一相似变换，不能据此宣称整个稠密场景严格保持同一个几何 gauge。

### 3.3 Local-Structure-Preserving Update Space

**本节问题：为什么限制更新空间，以及究竟保持了什么？对应 C2。**

先给出不变性约束：

```text
theta_tq* = theta_tq^0
beta_tq*  = beta_tq^0
V_tq*    = V_tq^0 + tau_tq^0 + delta_tau_tq
```

人体不应再被场景尺度整体缩放；它是以米为单位的参照，更新的是位置。场景尺度作用于相对深度与相机平移。

再给出世界坐标输出关系，明确沿用 camera-from-world：

```text
X_world = R_cw,t^T (X_camera - s t_cw,t^r)
```

最后说明 ray/tangent 参数化及有界更新怎样限制误差传播。详细坐标基构造和阈值留到附录。

可以严格陈述：相同局部人体顶点加上统一平移，不改变局部顶点差和局部人体结构。

不能扩大陈述：结构保持并不保证预测姿态正确，不保证世界坐标误差不会增加，也不保证所有命名为 MPJPE/PVE 的评估协议都对平移不敏感。

这里不应写成一整节“我们冻结了 NLF”，而要解释这项约束怎样阻止 C1 通过额外人体自由度吸收全局残差。

### 3.4 Observability-Guided Selective Updates

**本节问题：在什么证据下，哪些变量值得更新？对应 C3。**

按“取证 → 判断 → 更新 → 再取证”组织：

1. **取证：**以人体解剖区域为索引，分别收集自身表面、环境和其他人物干扰信息。现有 96-region TRSTR 是直接基础。
2. **判断：**区分观测有效性、预测置信度和方向可观测性；三者不能混为一谈。
3. **更新：**把方向信息转成尺度或位移的更新权重、边界或拒绝条件。解释它如何作用于 C1，而不是只给平移加一个新名称。
4. **再取证：**更新后重投影、重新判断可见性和局部对应，防止重复使用过期残差。

方向信息的实现可选择经验证的协方差预测、几何敏感度或其他明确机制，不要求为写作强加复杂求解器；但必须说明测量对象和作用方式。

若使用共享尺度与位移的联合信息表达，应把尺度与位移的相关性纳入考虑，不能仅给三个 XYZ 方向各一个权重就声称处理了尺度—位移歧义。混合无量纲尺度与米制位移时需说明归一化，否则条件数或阈值会随单位改变。

已有基础：ray/tangent votes、区域 gate、标量 log-variance、person gate、两次重投影。

待补强：方向相关证据以及它对共享尺度可更新程度的影响。学习到的方差不自动等价于几何可观测性，需要通过受控实验建立联系。

无有效观测时应明确保持、拒绝或有限继承规则；不要把任意回退结果宣称为恢复出的绝对尺度。

### 3.5 Training and Inference

**本节问题：上述机制如何学到，推理时真正执行什么？**

训练按任务分工解释，不逐项堆砌 loss：

- 尺度监督训练共享变量，不让局部人体错误成为错误尺度 teacher。
- 位移监督训练人物局部更新，覆盖沿视线与切向误差。
- clean/identity 与 no-worse 目标控制不必要修正。
- 可靠性相关目标支撑选择性更新，说明是掩码监督、误差监督还是方向信息监督。

现有 clean、scale-only、NLF-only、mixed 构造可作为起点，但需要检查干预含义。原稿 TRSTR 训练中的 scale case 会同时调整环境深度与目标人体位置，不应直接当成“只改变场景尺度、真实人体完全固定”的因果诊断。

两种构造可以共存，但必须分别命名、分别评估。

用一个算法框写完推理：提取冻结观测 → 初始化 → 组织共享/局部证据 → 受限选择性更新 → 重投影 → 输出世界几何。步骤必须对应最终实现，不能为叙事补画不存在的反馈箭头。

分阶段训练与联合推理并不矛盾，但需要明确“联合”发生在什么层面。只有级联时，应按级联描述。

### 开场：评价范围与协议

一段说明评估覆盖世界人体运动、场景度量几何、局部人体质量和人景放置。训练细节进入附录，各数据集的指标和对齐方式在对应小节说明，避免先占一大节介绍实验设置。

### 4.1 World-Space Human Motion

EMDB-2 作为首个主结果，突出原稿已有的 58.468 mm WA-MPJPE、149.959 mm W-MPJPE 和 1.079% RTE。解释各指标覆盖的运动层面，并选一组最有信息量的基线比较。

原有时序人景与轨迹图放在此处，紧邻世界运动表。结果的论证层级是整个系统的世界运动能力，不额外宣称已经隔离尺度、人体观察器和区域模块的独立贡献。

### 4.2 Metric Scene Reconstruction

以 Bonn 为主、TUM-Dynamic 为辅。先报告无需测试时 GT scale/shift 的 0.08599 Abs Rel 与 0.96377 threshold accuracy，说明框架输出的是可评价的度量深度，不只输出人体轨迹。

再用现有 TUM 相机曲线说明所依赖的相对相机几何质量。保留 VGGT-Ω 的结果归属和 Sim(3) 对齐说明，不将其误写为尺度校准降低了 ATE。

GT-scale oracle 曲线进入附录作为独立诊断，不与实际输出混成方法主结果。

### 4.3 Local Human Reconstruction

将 3DPW 写成一个紧凑小节，突出“保留强人体先验，同时处理全局位置”。明确 37.3/60.3/71.4 与 NLF 局部人体结果的关系，不把它包装成新的 pose/shape 改进。

无需为此新训练一个姿态更新模型。局部结构保持首先来自更新变量的定义，现有局部结果用于交代系统的人体质量。

### 4.4 Human–Scene Placement

集中放置原稿已有的坐、躺、倚靠及双人场景对比图和实物尺度图。围绕展示样例中的人体与邻近表面位置关系写观察，不将其扩展成拥挤场景鲁棒性或精确接触的定量结论。

用一个简短收束段连接全章：世界运动、场景度量、局部人体和几何放置分别呈现系统的不同能力。无需额外增加一个反复总结相同数值的 Analysis 小节。

### 贡献怎样进入这些结果

C1 作为系统的共享尺度与局部位置组织原则，由 4.1/4.2 展示整体结果；C2 由方法的固定变量定义与 4.3 对应；C3 通过方法中的区域证据及 4.4 的放置样例建立联系。当前结果不作为三个模块独立因果贡献或方向可观测性的消融证明。

## 10. 讨论、结论和附录

### Discussion and Limitations

集中讨论四个边界：人体体型先验存在偏差；多人共同定位偏差可能持续污染尺度；无人体或观测长期不足时无法凭空恢复尺度；固定姿态与形状限制了接触细节修复。

若 clip 级方法使用未来帧，明确非因果推理，避免继续未经说明地放入严格 online 分类。

### Conclusion

三到四句即可：重新点明尺度—位移耦合问题，概括结构化校准、局部保持与选择性更新，再给出实验支持的有限结论。不要再次逐个复述四个数据集的全部数值。

### Appendix

建议顺序：坐标与符号 → 完整结构与伪代码 → 训练/监督/扰动 → 数据与评估协议 → 扩展消融 → 计算成本 → 更多定性与失败例。

关键任务结果在正文呈现，附录补充已有复现细节和覆盖范围。不写“更多消融见附录”，除非确有相应实验。

1. 按现有结果版大纲重组实验表、图和段落，保持结果与对应方法版本一致。

4. 根据实验已经能够支持的结论重写 Introduction。
5. 最后压缩 Related Work、Abstract 和 Conclusion，统一术语和主张力度。

每个方法段按“困难 → 设计 → 工作方式 → 作用边界”写；每个实验段按“问题 → 控制条件 → 观察 → 有限结论”写。

避免用强形容词替代机制：将 “powerful / robust / significant” 换成具体误差、约束或比较；没有统计检验时不使用暗示统计显著性的表述。
