# GroundedHuman 左侧 teaser 设计探索

## 目标与参考边界

为论文左侧 teaser 提供 AI 生成的构图灵感，不设计右侧定量图，不作为实测重建结果。

论文来源：`.paper/my_paper/GroundedHuman.pdf`，重点为第 5–6 页的 Anchor-Scene Cross Attention、Multi-Scale Region Sampling 和 Regional Translation Prediction。论文只读；本任务不涉及模型移植、代码修改或 baseline 变动。

用户参考图 1 仅参考横向场景主视觉的排版；参考图 2 参考人体模型、错位残影与几何关系的视觉表达；参考图 3 参考接触部位的放大与 probes 表达。不沿用参考图 2 的重力映射、射线序列校正等方法内容。

## 内容与视觉语义

- 全局尺度：固定的人体度量先验与场景达成统一尺度，使用淡灰家具尺度轮廓提示校准，不用放大／缩小人体表达场景尺度校准。
- Anchor-scene：人体上的少量代表性 anchor 标记，对应局部场景证据。论文使用 24 anchors 和 3×3 局部场景 token 邻域；teaser 不必画满。
- 局部到区域：接触细节放大中表达细邻域、大邻域、自适应范围和外环上下文。论文的四种支持域在图像空间采样；示意覆盖层不应被解释为真实三维同心球或接触力场。
- Self/environment：人体表面采样用青色，环境采样用琥珀色，避免把所有采样都画成环境接触点。
- 平移修正：各区域预测带可靠性权重的全身平移建议，汇总后更新 root translation。残影与主模型应保持相同姿态和体型，不呈现独立肢体拉动。
- 接触结果：脚底贴地、手掌／前臂贴合家具；它们表达设计叙事，不代表模型具有硬接触保证。

## 两个构图方向

### A：坐姿沙发

单个青色人体坐在浅灰重建沙发上。手臂、坐垫和脚底形成多处接触关系；右侧两个小圆形镜头承载 probes 细节。优点是互动故事丰富，与用户参考图 3 的视觉语言接近。初稿残影被生成成不同姿态，因此修订稿去掉人体残影，并将放大镜改为横向并列。交付横版 `teaser_a_panorama.png`，1506×535。风险是手臂和座椅的遮挡较多，终稿需要用实际模型和选定视角校验。

### B：站姿扶台

站立人体单手扶台，脚底和手掌同时接触，主体高度完整可见。人体与家具尺度更易读取，主模型、尺度轮廓与少量局部证据构成一个连续场景。优点是缩小后容易读清，便于与右侧定量图组合。

已目视检查两版：A 横向构图、主体与文字完整；B 主体、手脚放大、整体平移残影可读。图中的同心采样轮廓是设计抽象，未严格表达四个图像支持域；场景尺度变化和区域可靠性汇总也经过简化，终稿不能直接把这些形状当作算法采样的精确可视化。

## 根据“方法思想与采样不可见”的反馈修订

交付更新为 `teaser_sampling_v3.png`，由 NBAI 生成主体与脚部素材，随后精确绘制采样网格。左侧用 body-anchor query 与 3×3 local scene tokens 的加权关联表达 cross attention；中央人体维持固定大小，家具尺度轮廓表示场景尺度校准。右侧画出 3×3、7×7、自适应方窗及外侧两行方环，窗口对齐图像坐标，不再以三维圆环表示采样。青色／橙色点分别示意 self-surface 与 environment。紫色区域建议与中央全身平移箭头表达区域证据的共同作用。

只读核对了 `vggt_omega/models/geometry/regional_scene_probe.py`：采样掩码使用 Chebyshev 距离，自适应半径依赖代表顶点投影范围，外环位于 adaptive 范围之外。也核对了 `hsi_refinement_head.py` 的局部 scene token gather，避免将 token 3×3 邻域与几何最近点搜索窗口混为一谈。

本图右侧用自适应 9×9、外侧两行的 13×13 范围作为一个具体示意；9×9 不是固定算法参数。采样点归属依据合成图颜色进行示意分配，不是模型真实 depth buffer 的计算结果。权重、区域投票同为示意，未执行推理。主项目源码无修改。
