# GroundedHuman v0.3 English Overleaf Package

## Upload

1. In Overleaf, choose **New Project -> Upload Project**.
2. Upload `GroundedHuman_v0.3_Overleaf_EN.zip`.
3. Open **Menu -> Settings -> Compiler** and select **XeLaTeX**.
4. Set `main.tex` as the main document if Overleaf does not select it automatically.
5. Click **Recompile**.

## Project Structure

- `main.tex`: English main paper.
- `appendix_en.tex`: complete English appendix.
- `references.bib`: bibliography database.
- `iclr2027_conference.sty` / `.bst`: local ICLR 2027 template files.
- `math_commands.tex`, `natbib.sty`, `fancyhdr.sty`: required local dependencies.
- `figures/`: all referenced image assets.
- `paper.pdf`: locally verified reference build.
- `latex_report_en.md`: compilation and visual-verification report.
- `translation_coverage_en.md`: Chinese-to-English coverage record.
