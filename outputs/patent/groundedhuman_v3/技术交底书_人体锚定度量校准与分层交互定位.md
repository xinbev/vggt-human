# 专利申请技术交底书

**拟定发明名称：一种基于人体锚定度量校准与分层交互定位的单目视频人景三维重建方法**

**专利类型建议：**发明专利。**技术领域：**计算机视觉、三维重建、人体运动捕捉。  
**申请人、发明人、技术联系人及联系方式：**由申请人确认后填写。  
**成果来源：**GroundedHuman V3 论文稿《GroundedHuman: Implicit Interaction Grounding for Dynamic Human–Scene Reconstruction》。本文是供专利代理人理解技术方案的交底稿，不是权利要求书。

## 一、发明要解决的技术问题

单目视频中的场景深度和相机平移通常只有相对尺度，人体估计器虽然能给出具有度量意义的体型和三维姿态，但人体、场景、相机三类结果若直接拼接，常在同一视频内出现尺度不统一、人体悬浮或与场景穿透。现有前馈式联合重建方法推理较快，却未充分利用人体局部结构去检索与其相关的场景证据；基于接触、碰撞等显式约束的方案往往依赖预先识别接触状态或推理时优化，在动态视频中增加处理环节。需要一种从单目视频出发、在统一度量坐标下重建场景、相机和人体运动，并依据人景几何关系直接修正人体位置的方法。

本发明的任务并非重新预测人体姿态或形状，而是：①利用有度量意义的人体几何为相对场景深度和相机平移确定同一尺度；②利用人体各区域与环境的局部及外围几何关系修正人体根部平移；③在人体位置改变后重新检索场景证据，以免沿用旧位置的交互特征。

## 二、现有技术及与本方案的区别

现有技术包括：分别从视频估计场景深度与相机运动、从图像估计参数化人体，然后组合输出；利用人体尺度对场景进行简单比例标定；以及通过接触标签、碰撞项、关键点重投影项或场景点云一致性项进行测试时联合优化。这些方向可以部分缓解尺度或接触问题，但单一深度比值容易混入人体定位误差、遮挡和场景深度误差；将人体与场景直接在全局范围匹配也容易受到其他人物和无关背景干扰。

提供的参考交底书《联合场景重建的全局人体运动捕捉方法》描述了基于点云一致性、SMPL 正则、重投影和相机项的联合优化。本方案的具体区别在于：先以人体可见表面和局部场景特征预测并稳定化场景的尺度及深度偏置，再对人体表面分区，在多级空间支持内区分本人表面、周边环境及他人干扰，直接预测带置信权重的根平移增量；更新位置后重建区域查询。推理阶段使用共享参数的有限次前馈更新，不要求显式接触标签，也不联合优化场景、相机、姿态和形状。参考交底书的法律状态、公开日及权属须由申请人与代理人核实，此处仅用于技术区分。

## 三、发明内容与整体方案

### 3.1 输入、输出及坐标约定

输入为同一单目摄像机拍摄的 RGB 视频帧 I₁…I_T，可含一人或多人。场景估计器输出每帧相对深度 Dᵣ,t、相机内参 K_t、相对相机外参 Tᵣ,cw,t 和多层图像特征 F_t；人体估计器输出每人的 SMPL 姿态 θ_tq、形状 β_tq、初始根平移 τ⁽⁰⁾_tq、人体顶点 V_tq^c 及置信度 c_tq。这里 t 为帧索引，q 为人索引，上标 c 表示相机坐标，下标 cw 表示世界到相机的变换。不同现有场景/人体估计器只要能提供相应观测量即可；V3 实施例采用冻结的 VGGT-Ω 和 NLF。

输出为共享度量世界坐标中的场景三维点 P_t^w、人体网格 M_tq^w 和相机轨迹。训练或推理中，人体局部姿态和形状保持其原有估计；本方案重点修正场景尺度、深度偏置及人体根平移。场景深度、相机平移和人体根位置的单位需经统一转换，所有投影和反投影均使用相同的内参及坐标约定。

### 3.2 方法步骤

**S101 获取基础观测。**对视频帧运行场景估计器，得到 Dᵣ、K、Tᵣ 和 F；运行人体估计器，得到各人的参数化人体、相机坐标中的顶点、根平移及置信度。两类估计器作为基础观测模块，可保持冻结。

**S102 建立人体与场景的初始尺度对应。**将可见人体表面采样点用 K_t 投影至 Dᵣ,t；筛除深度非有限、非正、投影越界或被更近人体表面遮挡的点，同一像素只保留最近的该人体表面。对有效对应集合 A_t 中每一点，计算人体相机深度与同射线相对场景深度之比，并取稳健中位数：sᶜ_t = median_{(q,i)∈A_t}([V^c_tqi]_z / Dᵣ,t(π(K_t,V^c_tqi)))。据此得到粗度量深度 D^coarse_t=sᶜ_t Dᵣ,t。无有效对应的帧不参加序列标定；整段均无有效对应时，可输出单位尺度并标记“标定无效”，不得把该回退值当作有效度量估计。

**S103 人体锚定的局部场景注意力校准。**在每人表面选取多个锚点，构造包括人体状态、锚点三维位置、图像投影、邻近场景几何、表面法向、距离及深度残差的锚点特征。先对锚点作自注意力编码人体整体结构，再以锚点为查询，从其投影附近的多层场景特征中作交叉注意力，聚合为人体级表征。两个轻量预测头输出残余对数尺度 Δlog s_tq 和深度加性偏置 b_tq。V3 的具体实施例使用每人 24 个锚点和投影周围 3×3 的场景特征邻域；锚点数与邻域大小是可调实现参数。

**S104 置信感知的序列度量稳定化。**将每人每帧的初始尺度与残余校正合成 s_tq=sᶜ_t exp(Δlog s_tq)，再按人体估计置信度合并同帧多人的结果，对有效帧在对数尺度上作稳健聚合，得到视频共享尺度 s；深度偏置同样聚合得到 b。将 s 同时作用于场景相对深度和相对相机平移，将 b 仅作用于深度：Dᵐ_t=sDᵣ,t+b，tᵐ_cw,t=s tᵣ_cw,t。相机旋转和内参不作此尺度变换。利用 K_t 对 Dᵐ_t 反投影，得到相机坐标中的度量场景点 Pᵐ_t。使初始人体根位置与这一度量场景参照一致。

**S105 构建分层人体区域与场景查询。**将每人参数化人体表面划分为对应的多个区域，每区以质心和表面采样顶点描述。围绕投影区域设置：小固定窗口、大固定窗口、随区域投影范围变化的自适应窗口、包围局部支持的外围环带。V3 实施例采用 96 个表面区域、每区质心加 8 个采样顶点、3×3 和 7×7 固定窗口。对每种支持分别建立人体区域状态查询与几何上下文查询，并从 F_t 和 Dᵐ_t 取得相应场景特征。

**S106 区分本人表面与环境并预测区域位移。**根据当前人体投影建立带实例归属的深度缓冲区。与当前人体可见深度在容差 ε_own 内一致的采样进入“本人表面”通道；与观测场景一致但不属于当前人的采样进入“环境”通道；属于其他人的采样不送入这两类注意力通道，而以干扰特征概括。无效采样由掩码屏蔽；某支持无有效采样时返回零特征及零有效比例。区域查询在各支持与归属通道中检索场景特征，并融合为人景交互表征 z_r。预测头对每区输出沿观察射线方向及其两个正交方向的位移系数、有效门控 g_r 和对数方差 ℓ_r；三个系数在相机坐标下组成区域根平移建议 v_r。上述关系由位置监督学习，不以显式脚部接触标签为必要输入。

**S107 聚合区域建议并重复定位。**令 m_r 表示该区是否有有效支持，区域权重 α_r=m_r g_r exp(−ℓ_r)。将所有有效区域建议加权为 v̂=(Σ_r α_r v_r)/max(Σ_r α_r, ε)。人员级门控 g_p 控制是否应用校正，先按每个坐标分量将 v̂ 截断到允许幅度，再更新 τ⁽ᵏ⁺¹⁾=τ⁽ᵏ⁾+g_p clip(v̂,−δ_max,δ_max)。V3 实施例共进行两次共享参数的前馈更新。每次更新后重新投影人体、更新实例归属并重建多级区域支持，之后再预测下一次位移；人体姿态、形状、场景几何和相机参数保持固定。

**S108 输出统一世界重建。**由度量深度与相机内参反投影场景点，并以度量相机外参的逆变换将场景点及已修正根位置的人体网格映射到同一世界坐标系。若采用 T_cw=[R|t] 的世界到相机约定，则相机点 x_c 对应 x_w=Rᵀ(x_c−t)。输出每帧人景几何、人体运动轨迹及相机轨迹；同时记录尺度标定是否有效，以便下游区分正常结果与回退结果。

### 3.3 一个可实施的训练方式

固定场景估计器和人体估计器，只训练度量校准模块与交互定位模块。先在具有度量深度和 SMPL 标注的数据上，对场景深度施加已知比例扰动，使校准模块学习从解析初始尺度恢复目标尺度与深度偏置；可用对数尺度绝对误差、偏置绝对误差、有效像素度量深度误差的加权和训练。V3 实施例采用 BEDLAM 作为该阶段数据。

定位模块训练时，对真实人体根平移和场景尺度施加合成扰动，同时混合未扰动、单独扰动及联合扰动状态。以剩余真实位移作为每次区域建议的目标，联合使用区域建议误差、最终根平移误差、门控二分类误差及更新幅度正则；对未扰动输入增加保持原位的约束，对扰动输入增加恢复约束，并惩罚使根平移误差变大的更新。随后可在具有人体或场景监督的视频数据上继续训练；V3 使用 EMDB 与 3DPW。训练损失和数据集属于具体实施例，推理方法不依赖这些数据集本身。

## 四、关键创新点与拟保护要点（供代理人提炼）

1. 人体可见表面沿相机射线建立初始人体—场景深度对应，联合局部场景注意力预测残余对数尺度和深度偏置，并经多人、多帧置信感知稳定化，对场景深度与相机平移施加同一共享尺度。
2. 以参数化人体表面区域为查询中心，同时读取点邻域、较大固定邻域、随人体区域变化的邻域及外围环境；把本人表面、场景环境和他人干扰区分后生成区域交互表征。
3. 每个区域预测三维位移建议、门控与不确定度，并按有效性、门控和不确定度聚合成受限的整人根平移校正；人体位置更新后重新计算区域投影、归属和支持特征，执行有限次共享参数更新。
4. 在场景和人体基础估计器冻结、人体姿态形状不变的条件下，完成度量场景校准与人体世界位置校正，形成单目视频共享度量坐标中的人景重建结果。可据此撰写方法、装置、电子设备及计算机可读存储介质的相应权利要求，具体范围由代理人结合检索结果确定。

锚点数、区域数、固定窗口尺寸、更新次数、基础估计器品牌或型号均为实施例参数；技术核心在上述对应、检索、可信聚合和更新机制的组合。

## 五、有益效果及证据边界

人体尺度对应给相对深度提供度量初值；局部场景特征修正单纯深度比值混合的尺度与定位误差；跨帧与跨人的置信聚合降低个别遮挡或误检对整段尺度的影响。对相机平移和场景深度使用同一尺度，有助于维持人景世界坐标的一致性。人体区域的多级查询、归属分离和可靠性加权使定位侧重相关场景表面，位置更新后重取上下文可避免旧位置特征与新位置不匹配。冻结基础估计器和有限次前馈修正使推理无需对全部变量进行测试时联合优化。

V3 论文稿的 RICH 消融表在相同度量标定前提下，记录关闭交互定位时碰撞帧比例为 12.83%，完整方法为 6.48%；穿透、悬浮和最大穿透等指标也在表中给出。该数字仅说明该论文稿报告的特定实验条件，不应外推为所有场景的保证性能；提交前应由发明人核对原始实验记录、对照设置与图表。对完全无人可见、深度严重缺失或人体估计明显错误的片段，本方法可能只能给出回退或置信不足的结果。
