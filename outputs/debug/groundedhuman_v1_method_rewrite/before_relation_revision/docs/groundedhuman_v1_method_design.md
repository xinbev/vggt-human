## 读者应当带走的思想

**人体提供读取场景的结构化接口，人体与场景的关系提供几何修正的依据。**

人体的形状、尺度和位置共同决定：去哪里取场景信息，以及怎样解释这些信息。将这种关系编码后，可以读出两类互补的修正：建立统一尺度的校准量，以及改善人体放置的位置更新。位置改变后，人和场景的关系也改变，因此重新读取场景。

英文核心句：

> We use the human body as a structured interface to the scene: its metric extent provides a reference for scene calibration, while its spatial configuration determines which scene observations are relevant to human placement.

“Interaction”在这里通过关系表示及其产生的位移体现，不需要先得到接触标签。正文以具体的查询、注意力汇聚和位移读出落实这一点。

老师给出的 `F(Q,K,V) → Metrics + Placement` 与 `F(Human × Scene) → Interaction` 可以整理成以下概念表达。此处只是解释思想，并非声称两个模块共享一个网络或一组参数：

\[
\text{Body--Scene Relations}
\xrightarrow{\text{Query / Attention}}
\text{Geometric Corrections}
=\{\text{Metric Calibration},\ \text{Placement Update}\}.
\]

其中 Metric Calibration 指尺度、深度偏置及其几何作用，不是评估指标 metrics。两类修正顺序执行：人体先给出场景的度量参照；校准后的场景再为人体位置提供证据。

## 为什么必须有两个模块

一个局部深度差可能由场景尺度不对、人体位置不对或观测不可靠造成。直接将深度差解释为人体位移，会混淆不同来源的误差。因此先估计公共度量参照，再在该参照下根据区域证据修正人体位置。置信度、有效性掩码和不确定性用于控制不可靠证据的影响。

这条因果关系贯穿方法开头、两个模块的起始段及公式说明。相比原稿按工程步骤介绍模块，现在强调每种表示要回答什么几何问题、为什么要这样读取场景、读出的结果如何作用于下一阶段。

## 方法结构

标题保持：**GroundedHuman: Implicit Interaction Grounding for Dynamic Human–Scene Reconstruction**。

| 模块 | 核心机制 | 回答的问题 | 输出 |
|---|---|---|---|
| Body-Anchored Metric Calibration | Metric Alignment Query | 怎样将场景表达在人体提供的度量参照中？ | 视频级尺度和深度偏置，并校准场景深度、相机平移 |
| Dynamic Interaction Grounding | Placement-Conditioned Interaction Attention | 在当前人—场景关系下，人体整体应该怎样移动？ | 可靠性加权的 root translation 更新 |

训练目标保留独立小节，属于两个模块的训练说明，不是第三个模型模块。

### Metric Alignment Query 的角色

保留人体表面深度比的解析初始化。24 个锚点包含人体状态、锚点位置、投影及附近几何差异，因此它们是带有明确几何含义的查询。

正文明确写出：Q 来自人体锚点，K/V 来自局部场景特征。人体内部 self-attention 汇集锚点证据，cross-attention 读取局部场景特征。聚合响应后预测残余尺度与深度偏置，再经过多人和多帧汇总形成公共参照。

尺度同时作用于深度和相机平移，偏置仅作用于深度。人体提供的是学习得到的米制先验，未假设它完全准确。

### Placement-Conditioned Interaction Attention 的角色

保留 96 个区域、每区域 8 个代表顶点、四种空间支持域、自身表面/环境两通道，以及其他人体干扰统计。

将采样点明确表述为相对于当前人体区域的关系编码。注意力在有效集合内选择和汇聚信息，形成 8 个上下文 token。正文给出带掩码注意力的数学式，并解释空集合返回零。

这里的注意力与当前几何绑定：人体移动后，采样位置、相对特征、样本归属和有效支持可能改变。每次更新都重新计算，因此 **Dynamic 指位置变化驱动的上下文更新**，不指跨帧注意力。

区域表示输出全身平移建议，经过有效性、门控和不确定性加权，以及人物级门控形成最终更新。两个步骤共享参数。固定场景、相机、姿态和形状，仅改变整体平移。

## 与 D4RT 的关系

阅读依据：`.paper/base_pdf/D4RT_paper.pdf` 的第 2 节、2.1–2.2 节、图 2 与表 1。

D4RT 的核心是：视频被编码为全局场景表示；查询指定源点、源时间、目标时间和参考相机，解码器返回三维位置。通过改变查询即可组织不同重建任务。其高层思想由具体查询接口支撑。

本次借鉴这种“让表示与读取方式承载核心思想”的写作组织。GroundedHuman 的查询对象和输出不同：人体结构组织场景读取，关系证据支持尺度校准与人体放置。没有移植 D4RT 模块，也没有新增全局隐式场、任意时空查询、多任务统一解码器或端到端联合训练等主张。

第一阶段的 Q/K/V 与第二阶段的关系注意力汇聚各有明确公式，不将后者改写成尚未采用的标准 cross-attention 架构。

## 新方法图的绘制依据

按用户最新要求，旧方法总图和旧方法细节图均退出编译正文，原图片文件保留。临时绘制的文本流程图也已撤下。正文和附录仅保留待重绘占位及新图注，图的最终设计由用户完成。

建议总图首先让读者看到“人体决定如何读取场景”的共同操作，然后区分两种读出。

1. 左侧输入：视频经 VGGT-Ω 和 NLF 得到相对场景/特征和米制人体。它们是基础观测来源。
2. 模块一：人体表面对应 → 粗尺度；几何条件化的人体锚点 Q → 局部场景 K/V → 残余校准；多人/多帧汇总 → 米制场景与相机平移。
3. 模块间主箭头：**calibrated metric reference**。明确第二模块使用第一模块校准后的几何。
4. 模块二：当前人体区域 → 多空间支持采样 → 自身表面/环境两通道 attention → 区域关系表示 → 可靠性加权平移更新。
5. 回环：更新后人体 → 重新投影与采样 → 更新后的 attention context。标注两步、共享参数；回环仅位于第二模块，不返回重新估计尺度。
6. 右侧输出：公共米制世界中的场景、相机轨迹与人体网格。

细节图适合展示 Q/K/V 的来源、四种空间支持、两种证据通道，以及从区域投票到整体更新的关系。其他人体用排除掩码/干扰统计表示。

不画时序稳定器、接触标签预测头、姿态更新头或独立的第三阶段。视频级中位数汇总与空间精修的迭代回环需要分别呈现。
